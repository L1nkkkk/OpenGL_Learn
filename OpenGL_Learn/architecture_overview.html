这套渲染引擎的亮点

适合对外展示 / 面试讲述 / 自己后续演进
亮点 01
运行时热重载链路完整
Shader 文件和 XML 材质都能在运行时直接改，保存后同步到画面，而且材质刷新已经带 revision，避免无意义的每帧重建。
亮点 02
渲染路径已经开始模块化
不是单个大 Draw 函数硬撑，而是明确拆成 RenderPass、Forward、Deferred、SSAO、Postprocess，为后续继续抽成 renderer graph 打了地基。
亮点 03
资源与场景编辑器雏形已经具备
ImGui 不只是 debug panel，而是有 docking、材质面板、reload 控件、viewport 调试和 scene state 存档的轻量编辑器外壳。
亮点 04
FBO 池化思路比较成熟
通过 FBOAttributes 去描述渲染目标，再统一交给 FramebufferManager 管理，避免各个 pass 自己散着造 framebuffer。
